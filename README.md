# Практическая работа №6. Шаблоны в FastAPI

Учебное приложение задач: FastAPI, Jinja2 и HTML-формы. Разработчик: MikeyKknv.

## Установка и запуск

Требуется Python 3.10 или новее. Выполняйте команды из корня проекта.

```bash
python -m venv venv
```

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Linux / macOS:

```bash
source venv/bin/activate
```

Установка и запуск (для любой ОС после активации):

```bash
python -m pip install -r requirements.txt
python -m uvicorn api:app --reload
```

Откройте http://127.0.0.1:8000/todo. Документация: http://127.0.0.1:8000/docs.

## Что показать на защите

1. Открыть `/todo`: сначала выводится сообщение об отсутствии задач.
2. Ввести текст и нажать «Добавить»: задача появится в списке, ID назначается автоматически.
3. Добавить вторую задачу: счётчик и список обновятся.
4. Нажать на текст задачи: откроется `/todo/{todo_id}` с её ID и текстом.
5. Вернуться к списку. Можно также добавлять задачи со страницы отдельной задачи.
6. Показать `{% extends "home.html" %}` и блок `todo_container` в обоих шаблонах.
7. Показать условия `if`, цикл `for`, `loop.index`, фильтр `length` и комментарий Jinja.
8. В `/docs` можно проверить оставшиеся PUT и DELETE, а затем обновить страницу списка.

## Файлы и назначение

- `api.py`: приложение и переход с `/` на `/todo`.
- `model.py`: модели данных и `Todo.as_form` для зависимости `Depends`.
- `todo.py`: маршруты, хранение задач и передача контекста в Jinja2.
- `templates/home.html`: базовый шаблон страницы.
- `templates/todo.html`: дочерний шаблон, форма, список и отдельная задача.
- `requirements.txt`: зависимости приложения.

## Изменения относительно предыдущей работы

GET `/todo` и GET `/todo/{todo_id}` теперь возвращают HTML вместо JSON.
POST `/todo` принимает поле формы `item` вместо JSON с ID. После добавления сервер
возвращает перенаправление 303 на список; браузер выполняет GET и показывает HTML.
Это предотвращает повторное добавление при обновлении страницы.
PUT `/todo/{todo_id}`, DELETE `/todo/{todo_id}` и DELETE `/todo` остаются JSON API.
Форм редактирования и удаления нет: они не требуются в задании №6.
Ссылки используют настоящий ID, а не порядковый номер строки.

Данные хранятся в памяти и теряются при перезапуске, в том числе при автоматической
перезагрузке сервера после редактирования кода. Для демонстрации запускайте один
процесс приложения. Bootstrap загружается из CDN: без интернета функциональность
сохранится, но оформление будет базовым.

`1pr/api.py` и `books_router.py` относятся к другим заготовкам и не подключаются
к этому приложению; для работы №6 их менять не нужно.
